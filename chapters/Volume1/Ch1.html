公式 01

絕對值不等式的解與圖形

核心公式（設 $a \gt 0$，$b \in \mathbb{R}$）
原點型（距離原點）
$$|x| \le a \iff -a \le x \le a$$ $$|x| \ge a \iff x \le -a \text{ 或 } x \ge a$$
平移型（距離點 $b$）
$$|x - b| \le a \iff b - a \le x \le b + a$$ $$|x - b| \gt a \iff x \lt b - a \text{ 或 } x \gt b + a$$
圖示：$b$ 為區間中心（兩端點中點），$a$ 為半寬（中心到端點距離）；實心點包含端點，空心點不包含端點。
觀念重點
  • 幾何意義：$|x - b|$ 表示數線上點 $x$ 到點 $b$ 的距離，解題時常利用「中點 $b = \frac{\alpha + \beta}{2}$」與「半徑 $a = \frac{\beta - \alpha}{2}$」反推不等式。
  • 方向口訣：「小於取中間（連寫成單一區間），大於取兩邊（以『或』連接）」。
常見易錯點提醒
  • 常數負號陷阱：若右側為負數，例如 $|x - 2| \lt -3$ 無實數解，而 $|x - 2| \gt -3$ 為任意實數皆成立，不可直接套公式展開。
  • 係數負號未先提：遇到 $|ax + c| \le b$ 反推時，若 $a \lt 0$ 須記得 $|ax + c| = |-ax - c|$，先將 $x$ 的係數化為正數或檢驗中點正負。
課堂範例 1

已知不等式 $|ax + 2| \le b$（其中 $b \gt 0$）的實數解為 $-1 \le x \le 5$，試求數對 $(a, b)$。

解題提示：先將解集合 $-1 \le x \le 5$ 利用「中點與半徑」改寫為 $|x - m| \le r$ 的標準形式，再與 $|ax + 2| \le b$ 比較係數。
點我看詳解

1. 由區間 $-1 \le x \le 5$ 求中心與半寬：

中點 $m = \dfrac{-1 + 5}{2} = 2$，半徑 $r = \dfrac{5 - (-1)}{2} = 3$，因此原解等價於 $|x - 2| \le 3$。

2. 觀察不等式 $|ax + 2| \le b$，令絕對值內部為 $0$ 得中心點 $x = -\dfrac{2}{a}$。

因為中心點必須為 $2$，故 $-\dfrac{2}{a} = 2 \implies a = -1$。

3. 將 $a = -1$ 代回原式得 $|-x + 2| \le b \iff |x - 2| \le b$，與 $|x - 2| \le 3$ 比較即得 $b = 3$。

答：$(a, b) = (-1, 3)$

公式 02

乘法公式

核心公式

1. 二次與平方差公式：

$$(a \pm b)^2 = a^2 \pm 2ab + b^2, \qquad (a + b)(a - b) = a^2 - b^2$$ $$(a + b + c)^2 = a^2 + b^2 + c^2 + 2(ab + bc + ca)$$

2. 三次和差與立方和差公式：

$$(a \pm b)^3 = a^3 \pm 3a^2b + 3ab^2 \pm b^3 = a^3 \pm b^3 \pm 3ab(a \pm b)$$ $$a^3 + b^3 = (a + b)(a^2 - ab + b^2) = (a + b)^3 - 3ab(a + b)$$ $$a^3 - b^3 = (a - b)(a^2 + ab + b^2) = (a - b)^3 + 3ab(a - b)$$
觀念重點
  • 對稱式求值：題目若給定 $a + b$ 與 $ab$（或倒數型 $x + \frac{1}{x}$，此時 $ab = 1$），優先選用「和／積變形版」：$a^2 + b^2 = (a + b)^2 - 2ab$、$a^3 + b^3 = (a + b)^3 - 3ab(a + b)$。
  • 因式分解視角：立方和差乘積式 $(a \pm b)(a^2 \mp ab + b^2)$ 常用於約分與分式化簡。
常見易錯點提醒
  • 正負號混淆：$a^3 - b^3 = (a - b)(a^2 + ab + b^2)$ 括號內中間項係數是 $+1$ 而非 $+2$，也不可以誤記為 $-ab$。
  • 由 $(x - \frac{1}{x})$ 求 $(x + \frac{1}{x})$：$(x + \frac{1}{x})^2 = (x - \frac{1}{x})^2 + 4$，開根號時需注意 $x$ 的正負範圍以決定是否取正負兩解。
課堂範例 2

已知實數 $x$ 滿足 $x + \dfrac{1}{x} = 3$，試求下列各式的值：(1) $x^2 + \dfrac{1}{x^2}$；(2) $x^3 + \dfrac{1}{x^3}$。

解題提示：把 $a = x$、$b = \dfrac{1}{x}$ 看成一對數，注意兩數乘積 $ab = x \cdot \dfrac{1}{x} = 1$ 為定值！
點我看詳解

(1) 利用 $a^2 + b^2 = (a + b)^2 - 2ab$：

$$x^2 + \frac{1}{x^2} = \left(x + \frac{1}{x}\right)^2 - 2\left(x \cdot \frac{1}{x}\right) = 3^2 - 2(1) = 7$$

(2) 利用 $a^3 + b^3 = (a + b)^3 - 3ab(a + b)$：

$$x^3 + \frac{1}{x^3} = \left(x + \frac{1}{x}\right)^3 - 3\left(x \cdot \frac{1}{x}\right)\left(x + \frac{1}{x}\right) = 3^3 - 3(1)(3) = 27 - 9 = 18$$

答：(1) $7$　(2) $18$

公式 03

分點公式

核心公式

設數線上兩點 $A(a)$、$B(b)$，點 $P(x)$ 在線段 $\overline{AB}$ 上，且 $\overline{AP} : \overline{PB} = m : n$（$m, n \gt 0$），則：

$$x = \frac{na + mb}{m + n}$$

中點特例：當 $m = n$ 時，$\overline{AB}$ 之中點坐標為 $M\!\left(\dfrac{a + b}{2}\right)$。

圖示：記住「交叉乘」——距離 $A$ 的比例 $m$ 要乘到對面端點 $b$，距離 $B$ 的比例 $n$ 要乘到端點 $a$。
觀念重點
  • 加權思想：離哪一點較近，該點所占的權重就較大；公式本質上是 $\frac{n}{m+n}a + \frac{m}{m+n}b$。
  • 外分點轉內分點：題目若說點 $P$ 在「直線 $AB$ 上」，除線段內的點外，還須考慮位於 $A$ 左側或 $B$ 右側的外分點，先畫出相對位置再套內分點公式最不易出錯。
常見易錯點提醒
  • 分子順序寫反：常誤寫成 $\frac{ma + nb}{m + n}$，交卷前可用極端檢驗——若 $m \lt n$，則 $P$ 應較靠近 $A$，算出的 $x$ 必須離 $a$ 較近。
  • 漏掉外分點：題幹寫「直線 $AB$ 上」且 $m \neq n$ 時，通常有 2 個解（1 內分點、1 外分點）；寫「線段 $\overline{AB}$ 上」時才只有 1 個內分點。
課堂範例 3

設數線上兩點 $A(-3)$、$B(12)$，已知點 $P$ 在直線 $AB$ 上且滿足 $\overline{AP} : \overline{PB} = 2 : 3$，試求點 $P$ 的所有可能坐標。

解題提示：分兩類討論——(1) $P$ 在 $\overline{AB}$ 之間（內分點）；(2) $P$ 在 $\overline{AB}$ 之外（因為 $\overline{AP} \lt \overline{PB}$，外分點 $P$ 必位於 $A$ 的左側）。
點我看詳解

情況一：$P(x)$ 在線段 $\overline{AB}$ 上（內分點）

由內分點公式（$m = 2, n = 3$）：

$$x = \frac{3 \times (-3) + 2 \times 12}{2 + 3} = \frac{-9 + 24}{5} = \frac{15}{5} = 3$$

情況二：$P(x)$ 在線段 $\overline{AB}$ 外（外分點）

因為 $\overline{AP} : \overline{PB} = 2 : 3$（即 $\overline{AP} \lt \overline{PB}$），$P$ 離 $A$ 較近，故三點順序為 $P - A - B$，此時 $\overline{PA} : \overline{AB} = 2 : (3 - 2) = 2 : 1$。

視 $A(-3)$ 為線段 $\overline{PB}$ 的內分點，套用分點公式：

$$-3 = \frac{1 \cdot x + 2 \cdot 12}{2 + 1} \implies -9 = x + 24 \implies x = -33$$

答：$P$ 的坐標為 $3$ 或 $-33$

公式 04

雙重根式

核心公式（設 $a, b \gt 0$）
$$\sqrt{(a + b) + 2\sqrt{ab}} = \sqrt{a} + \sqrt{b}$$ $$\sqrt{(a + b) - 2\sqrt{ab}} = |\sqrt{a} - \sqrt{b}| = \sqrt{a} - \sqrt{b} \quad (\text{當 } a \ge b)$$
觀念重點
  • 化簡原則：利用 $(\sqrt{a} \pm \sqrt{b})^2 = (a + b) \pm 2\sqrt{ab}$，拆解「和為外項、積為內項」的兩數 $a, b$。
  • 內層係數不為 $2$ 時：
    • 係數為 $2k$（如 $6\sqrt{2}$）：將 $k$ 移入根號內（$6\sqrt{2} = 2\sqrt{18}$）。
    • 係數為奇數或 $1$（如 $\sqrt{4 + \sqrt{15}}$）：分子分母同乘 $2$，改寫為 $\dfrac{\sqrt{8 + 2\sqrt{15}}}{\sqrt{2}}$ 再化簡。
常見易錯點提醒
  • 負值陷阱：計算 $\sqrt{(a+b) - 2\sqrt{ab}}$ 時，開出來必須為正數或 $0$，務必「大數減小數」（$\sqrt{a} - \sqrt{b}$，其中 $a \ge b$）。
  • 忘記調整係數 $2$：看到 $\sqrt{7 + \sqrt{40}}$ 就直接找兩數和 $7$、積 $40$ 是錯的！必須先化為 $\sqrt{7 + 2\sqrt{10}}$ 才能拆成 $5$ 和 $2$。
課堂範例 4

試化簡下列各雙重根式：(1) $\sqrt{8 - 2\sqrt{15}}$；(2) $\sqrt{4 + \sqrt{15}}$。

解題提示：第 (1) 題內層根號前已有 $2$，找出和為 $8$、積為 $15$ 的兩數；第 (2) 題根號內乘以 $\dfrac{2}{2}$ 湊出係數 $2$。
點我看詳解

(1) 因為 $5 + 3 = 8$ 且 $5 \times 3 = 15$（取 $a = 5 \gt b = 3$）：

$$\sqrt{8 - 2\sqrt{15}} = \sqrt{(5 + 3) - 2\sqrt{5 \times 3}} = \sqrt{5} - \sqrt{3}$$

(2) 先將根號內同乘 $\dfrac{2}{2}$ 製造出 $2$：

$$\sqrt{4 + \sqrt{15}} = \sqrt{\frac{8 + 2\sqrt{15}}{2}} = \frac{\sqrt{8 + 2\sqrt{15}}}{\sqrt{2}} = \frac{\sqrt{5} + \sqrt{3}}{\sqrt{2}}$$

再將分母有理化（上下同乘 $\sqrt{2}$）：

$$\frac{(\sqrt{5} + \sqrt{3})\sqrt{2}}{2} = \frac{\sqrt{10} + \sqrt{6}}{2}$$

答：(1) $\sqrt{5} - \sqrt{3}$　(2) $\dfrac{\sqrt{10} + \sqrt{6}}{2}$

公式 05

算幾不等式

核心公式

對任意兩正實數 $a \gt 0, b \gt 0$（亦可推廣至 $a, b \ge 0$），其算術平均數恆大於或等於幾何平均數：

$$\frac{a + b}{2} \ge \sqrt{ab}$$

等號成立條件：當且僅當 $a = b$ 時，等號成立。

觀念重點
  • 極值口訣「和定積最大，積定和最小」：已知 $a + b$ 為定值可求 $ab$ 最大值；已知 $ab$ 為定值可求 $a + b$ 最小值。
  • 配湊定值：若 $a$ 與 $b$ 乘積不為常數，例如求 $x + \frac{4}{x-1}$（$x \gt 1$）最小值時，應先改寫為 $(x - 1) + \frac{4}{x - 1} + 1$，使兩項相乘後變數消去。
常見易錯點提醒
  • 必須檢驗正數條件（一正）：兩項皆須為正數（或非負）才能套用算幾不等式；若出現負數需先提出負號或更換變數。
  • 必須檢驗等號成立（三相等）：算出上界／下界後，務必解出 $a = b$ 是否落在題目允許的變數範圍內，否則該界限值不可作為極值！
課堂範例 5

設正實數 $x, y$ 滿足 $2x + 3y = 12$，試求 $xy$ 的最大值，以及此時 $(x, y)$ 之值。

解題提示：令算幾不等式中的兩正數分別為 $a = 2x$ 與 $b = 3y$，切記不要誤令成 $x$ 與 $y$。
點我看詳解

1. 因為 $x \gt 0, y \gt 0$，所以 $2x \gt 0$ 且 $3y \gt 0$，可由算幾不等式得：

$$\frac{2x + 3y}{2} \ge \sqrt{(2x)(3y)}$$

2. 將 $2x + 3y = 12$ 代入：

$$\frac{12}{2} \ge \sqrt{6xy} \implies 6 \ge \sqrt{6xy}$$

兩邊平方得 $36 \ge 6xy \implies xy \le 6$，故 $xy$ 的最大值為 $6$。

3. 檢驗等號成立條件：當且僅當 $2x = 3y$ 時等號成立。

搭配 $2x + 3y = 12$ 得 $2x = 3y = 6$，解得 $x = 3$，$y = 2$（皆為正數，符合條件）。

答：$xy$ 最大值為 $6$，此時 $(x, y) = (3, 2)$

公式 06

有理數指數的定義

核心公式（設 $a \gt 0, b \gt 0$，$n \in \mathbb{N}$，$m \in \mathbb{Z}$，$r, s \in \mathbb{Q}$）
零指數與負指數
$$a^0 = 1, \qquad a^{-n} = \frac{1}{a^n}$$
分數指數（根式互換）
$$a^{\frac{1}{n}} = \sqrt[n]{a}, \qquad a^{\frac{m}{n}} = \sqrt[n]{a^m} = (\sqrt[n]{a})^m$$

指數律：$a^r \cdot a^s = a^{r+s}$、$\dfrac{a^r}{a^s} = a^{r-s}$、$(a^r)^s = a^{rs}$、$(ab)^r = a^r b^r$。

觀念重點
  • 底數化簡優先：計算分數次方時，優先把底數化為質因數或小整數的次方（例如 $\frac{27}{8} = (\frac{3}{2})^3$），再進行次方相乘約分。
  • 結合乘法公式：形如 $a^{\frac{1}{2}} + a^{-\frac{1}{2}}$ 與 $a + a^{-1}$ 之間，剛好是平方與立方的對稱關係（兩數互為倒數，乘積為 $1$）。
常見易錯點提醒
  • 負底數不能任意套分數指數律：例如 $(-8)^{\frac{2}{6}} = (-8)^{\frac{1}{3}} = -2$，但 $\sqrt[6]{(-8)^2} = +2$，因此有理數指數規定底數必須大於 $0$（$a \gt 0$）。
  • 負指數不是負數：$2^{-3} = \frac{1}{2^3} = \frac{1}{8} \gt 0$，千萬不要誤寫成 $-8$ 或 $-6$。
課堂範例 6

設 $a \gt 0$，試求下列各式的值：(1) $\left(\dfrac{27}{8}\right)^{-\frac{2}{3}} \times 9^{\frac{1}{2}}$；(2) 若 $a^{\frac{1}{2}} + a^{-\frac{1}{2}} = 4$，求 $a + a^{-1}$。

解題提示：第 (1) 題把底數換成 $\dfrac{3}{2}$ 與 $3$ 的次方；第 (2) 題將已知條件兩邊同時平方，注意 $a^{\frac{1}{2}} \cdot a^{-\frac{1}{2}} = a^0 = 1$。
點我看詳解

(1) 將底數化為次方型式再套用指數律：

$$\left(\frac{27}{8}\right)^{-\frac{2}{3}} \times 9^{\frac{1}{2}} = \left[\left(\frac{3}{2}\right)^3\right]^{-\frac{2}{3}} \times (3^2)^{\frac{1}{2}} = \left(\frac{3}{2}\right)^{-2} \times 3^1 = \frac{4}{9} \times 3 = \frac{4}{3}$$

(2) 將 $a^{\frac{1}{2}} + a^{-\frac{1}{2}} = 4$ 兩邊平方：

$$\left(a^{\frac{1}{2}} + a^{-\frac{1}{2}}\right)^2 = 4^2$$ $$a + 2\left(a^{\frac{1}{2}} \cdot a^{-\frac{1}{2}}\right) + a^{-1} = 16 \implies a + 2(1) + a^{-1} = 16 \implies a + a^{-1} = 14$$

答：(1) $\dfrac{4}{3}$　(2) $14$

公式 07

科學記號

核心公式

任一正實數 $x \gt 0$ 皆可唯一表為科學記號：

$$x = a \times 10^n \quad (\text{其中 } 1 \le a \lt 10,\; n \in \mathbb{Z})$$

判讀與數量級：

1. 若 $n \ge 0$，則 $x$ 的整數部分為 $n + 1$ 位數；若 $n \lt 0$，則 $x$ 從小數點後第 $|n|$ 位開始出現非零數字。

2. 數量級（以 $\sqrt{10} \approx 3.162$ 為分界）：若 $1 \le a \lt \sqrt{10}$，數量級為 $10^n$；若 $\sqrt{10} \le a \lt 10$，數量級為 $10^{n+1}$。

觀念重點
  • 為何分界點是 $\sqrt{10}$：在對數尺度（$\log_{10}$）上，$\log 1 = 0$、$\log 10 = 1$，中點 $\frac{1}{2}$ 對應到 $10^{0.5} = \sqrt{10} \approx 3.162$，而非算術中點 $5$。
  • 科學記號乘除：數字部分先相乘除，次方部分利用 $10^p \cdot 10^q = 10^{p+q}$ 合併，最後調整 $a$ 至 $[1, 10)$ 區間。
常見易錯點提醒
  • 數量級誤用四捨五入分界 $5$：例如 $4.2 \times 10^8$，因 $4.2 \ge 3.162$，其數量級是 $10^9$ 而非 $10^8$！
  • 係數超過或小於範圍：算完得到 $12 \times 10^5$ 或 $0.6 \times 10^{-3}$ 尚未完成，必須調整為 $1.2 \times 10^6$ 與 $6 \times 10^{-4}$。
課堂範例 7

已知光速約為 $3 \times 10^8$ 公尺/秒，一年約有 $3.15 \times 10^7$ 秒，試求 1 光年距離的科學記號表示法、整數部分為幾位數，以及其數量級為何？

解題提示：距離 $=$ 速率 $\times$ 時間。算出科學記號 $a \times 10^n$ 後，比較 $a$ 與 $\sqrt{10} \approx 3.162$ 的大小來決定數量級。
點我看詳解

1. 計算 1 光年距離：

$$d = (3 \times 10^8) \times (3.15 \times 10^7) = (3 \times 3.15) \times 10^{8+7} = 9.45 \times 10^{15}\text{（公尺）}$$

因為 $1 \le 9.45 \lt 10$，已經是標準科學記號。

2. 判斷位數：指數 $n = 15$，故整數部分為 $15 + 1 = 16$ 位數。

3. 判斷數量級：因為 $9.45 \ge \sqrt{10} \approx 3.162$，所以數量級為 $10^{15+1} = 10^{16}$ 公尺。

答：$9.45 \times 10^{15}$ 公尺、$16$ 位數、數量級 $10^{16}$ 公尺

公式 08

常用對數的定義

核心公式

對任意正實數 $x \gt 0$，若 $10^y = x$，則稱 $y$ 為 $x$ 的常用對數，記作 $\log x = y$：

$$10^y = x \iff y = \log x \quad (x \gt 0)$$
基本恆等與運算律（$a, b \gt 0$）
$$\log 1 = 0,\quad \log 10 = 1,\quad 10^{\log x} = x$$ $$\log(ab) = \log a + \log b,\quad \log a^r = r\log a$$
首數與尾數應用

設 $\log x = n + \alpha$（$n \in \mathbb{Z}$，$0 \le \alpha \lt 1$），則 $x = 10^\alpha \times 10^n$：

首數 $n$ 決定位數／首位小數位置；尾數 $\alpha$ 決定最高位數字。

觀念重點
  • 對數就是「以 10 為底的指數」：求巨大次方數（如 $2^{20}$、$3^{50}$）的位數時，取 $\log$ 即可把次方運算降階為乘法。
  • 估計最高位數字：將尾數 $\alpha$ 夾在兩個已知對數值 $\log k \le \alpha \lt \log(k + 1)$ 之間（常見需記 $\log 2 \approx 0.3010$、$\log 3 \approx 0.4771$、$\log 7 \approx 0.8451$），即可推得 $k \le 10^\alpha \lt k + 1$，故首位數字為 $k$。
常見易錯點提醒
  • 真數必須為正：$\log x$ 僅在 $x \gt 0$ 時有意義；$\log 0$ 與 $\log(-2)$ 皆無意義。
  • 負對數的首數與尾數切忌寫反：尾數 $\alpha$ 規定必須滿足 $0 \le \alpha \lt 1$（非負）！例如 $\log x = -4.771$ 時，應拆成 $-5 + 0.229$（首數 $-5$、尾數 $0.229$），不可寫成 $-4 + (-0.771)$。
課堂範例 8

已知 $\log 2 \approx 0.3010$、$\log 3 \approx 0.4771$，試判斷 $2^{20}$ 為幾位數，且其最高位數字為何？

解題提示：先算 $\log(2^{20}) = 20 \log 2$，再拆成「整數首數 $n$ $+$ 非負尾數 $\alpha$」，由 $n + 1$ 得位數，由 $\alpha$ 的範圍找最高位數字。
點我看詳解

1. 取常用對數：

$$\log(2^{20}) = 20 \log 2 \approx 20 \times 0.3010 = 6.020 = 6 + 0.020$$

2. 判斷位數：首數 $n = 6$，代表 $2^{20} = 10^{0.020} \times 10^6$，故為 $6 + 1 = 7$ 位數。

3. 判斷最高位數字：尾數 $\alpha = 0.020$，因為 $\log 1 = 0 \le 0.020 \lt \log 2 \approx 0.3010$，

所以 $1 \le 10^{0.020} \lt 2$，即最高位數字為 $1$。（驗證：$2^{20} = 1,048,576$，確實是 $7$ 位數、最高位 $1$）

答：$7$ 位數，最高位數字為 $1$

練習 1 基礎 對應：公式 01、03

解絕對值不等式 $|2x - 5| \gt 3$，並求此不等式解集合所對應數線兩端點的中點坐標。

解題提示：「大於取兩邊」拆成 $2x - 5 \lt -3$ 或 $2x - 5 \gt 3$，再用中點公式求兩端點平均值。
點我看詳解

1. 由 $|2x - 5| \gt 3$ 得：

$$2x - 5 \lt -3 \quad \text{或} \quad 2x - 5 \gt 3$$ $$2x \lt 2 \quad \text{或} \quad 2x \gt 8 \implies x \lt 1 \text{ 或 } x \gt 4$$

2. 兩端點分別為 $1$ 與 $4$，中點坐標為 $\dfrac{1 + 4}{2} = \dfrac{5}{2}$（亦恰為 $2x - 5 = 0$ 之解）。

答：$x \lt 1$ 或 $x \gt 4$；中點坐標為 $\dfrac{5}{2}$

練習 2 基礎 對應：公式 04、06

試化簡算式 $\sqrt{11 + 6\sqrt{2}} - 8^{\frac{2}{3}} + \left(\dfrac{1}{4}\right)^{-\frac{1}{2}}$。

解題提示：先將 $6\sqrt{2}$ 改寫成 $2\sqrt{18}$ 化簡雙重根式，再把 $8 = 2^3$ 與 $\dfrac{1}{4} = 2^{-2}$ 化為指數形式。
點我看詳解

1. 化簡雙重根式：$6\sqrt{2} = 2 \cdot 3\sqrt{2} = 2\sqrt{18}$，因 $9 + 2 = 11$ 且 $9 \times 2 = 18$，故：

$$\sqrt{11 + 6\sqrt{2}} = \sqrt{11 + 2\sqrt{18}} = \sqrt{9} + \sqrt{2} = 3 + \sqrt{2}$$

2. 計算有理數指數項：

$$8^{\frac{2}{3}} = (2^3)^{\frac{2}{3}} = 2^2 = 4, \qquad \left(\frac{1}{4}\right)^{-\frac{1}{2}} = (2^{-2})^{-\frac{1}{2}} = 2^1 = 2$$

3. 合併：$(3 + \sqrt{2}) - 4 + 2 = 1 + \sqrt{2}$。

答：$1 + \sqrt{2}$

練習 3 進階 對應：公式 02、06

已知實數 $x$ 滿足 $2^x - 2^{-x} = 2$，試求下列各式的值：(1) $4^x + 4^{-x}$；(2) $8^x - 8^{-x}$。

解題提示：令 $t = 2^x$，則 $4^x = t^2$、$8^x = t^3$，直接套用 $(t - \frac{1}{t})^2$ 與立方差乘法公式即可。
點我看詳解

(1) 將 $2^x - 2^{-x} = 2$ 兩邊平方：

$$\left(2^x - 2^{-x}\right)^2 = 4^x - 2\left(2^x \cdot 2^{-x}\right) + 4^{-x} = 4^x - 2 + 4^{-x} = 4$$

移項得 $4^x + 4^{-x} = 6$。

(2) 利用立方差公式 $a^3 - b^3 = (a - b)^3 + 3ab(a - b)$（令 $a = 2^x, b = 2^{-x}$）：

$$8^x - 8^{-x} = (2^x)^3 - (2^{-x})^3 = (2^x - 2^{-x})^3 + 3(2^x \cdot 2^{-x})(2^x - 2^{-x}) = 2^3 + 3(1)(2) = 8 + 6 = 14$$

答：(1) $6$　(2) $14$

練習 4 進階 對應：公式 07、08

已知 $\log 2 \approx 0.3010$、$\log 3 \approx 0.4771$，試求 $\left(\dfrac{1}{3}\right)^{10}$ 化為小數後，從小數點後第幾位開始出現不為 $0$ 的數字？且該首位非零數字為何？

解題提示：取對數後會得到負數，務必拆成「負整數首數 $n$ $+$ 正的尾數 $\alpha$（$0 \le \alpha \lt 1$）」。
點我看詳解

1. 取常用對數：

$$\log\left(\frac{1}{3}\right)^{10} = \log\left(3^{-10}\right) = -10\log 3 \approx -10 \times 0.4771 = -4.771$$

2. 拆解為「整數首數 $+$ 非負尾數」：

$$-4.771 = -5 + (5 - 4.771) = -5 + 0.229$$

3. 因為首數 $n = -5$，代表 $\left(\dfrac{1}{3}\right)^{10} = 10^{0.229} \times 10^{-5}$，所以從小數點後第 $5$ 位開始不為 $0$。

4. 尾數 $\alpha = 0.229$ 滿足 $\log 1 = 0 \le 0.229 \lt \log 2 \approx 0.3010$，故 $1 \le 10^{0.229} \lt 2$，首位非零數字為 $1$。

答：小數點後第 $5$ 位開始不為 $0$；首位非零數字為 $1$

練習 5 挑戰 對應：公式 05

某農夫利用一面牆當作一邊，用總長 $40$ 公尺的籬笆圍成一個矩形菜園，並在菜園內部平行於寬邊加設 $1$ 道隔間籬笆將菜園分為兩個小矩形。設菜園垂直於牆的寬為 $x$ 公尺，平行牆面的總長為 $y$ 公尺（籬笆總長滿足 $3x + y = 40$），試求菜園的最大總面積，以及此時菜園的寬 $x$ 與總長 $y$。

解題提示：總面積為 $xy$，已知 $3x + y = 40$ 為定值，將 $3x$ 與 $y$ 代入算幾不等式求 $xy$ 上界，再由等號成立條件解 $x, y$。
點我看詳解

1. 因為長寬皆為正數（$x \gt 0, y \gt 0$），對正數 $3x$ 與 $y$ 使用算幾不等式：

$$\frac{3x + y}{2} \ge \sqrt{(3x)(y)}$$

2. 代入 $3x + y = 40$：

$$\frac{40}{2} \ge \sqrt{3xy} \implies 20 \ge \sqrt{3xy} \implies 400 \ge 3xy \implies xy \le \frac{400}{3}$$

3. 檢驗等號成立條件：當且僅當 $3x = y$ 時，面積達到最大值 $\dfrac{400}{3}$。

搭配 $3x + y = 40$ 得 $3x = y = 20$，解得 $x = \dfrac{20}{3}$ 公尺，$y = 20$ 公尺（皆為正數，合理）。

答：最大總面積為 $\dfrac{400}{3}$ 平方公尺，此時寬 $x = \dfrac{20}{3}$ 公尺、總長 $y = 20$ 公尺

練習 6 挑戰 對應：公式 04、02

設 $\sqrt{9 + 4\sqrt{5}}$ 的整數部分為 $a$，小數部分為 $b$，試求 $a$、$b$ 的值，並求 $b^2 + \dfrac{1}{b^2}$ 之值。

解題提示：先將 $\sqrt{9 + 4\sqrt{5}}$ 改寫成 $\sqrt{9 + 2\sqrt{20}}$ 化簡雙重根式，估計整數部分 $a$ 後得 $b = \text{原數} - a$，再求 $\dfrac{1}{b}$ 有理化！
點我看詳解

1. 化簡雙重根式：將 $4\sqrt{5}$ 改為 $2 \cdot 2\sqrt{5} = 2\sqrt{20}$，因 $5 + 4 = 9$ 且 $5 \times 4 = 20$：

$$\sqrt{9 + 4\sqrt{5}} = \sqrt{9 + 2\sqrt{20}} = \sqrt{5} + \sqrt{4} = \sqrt{5} + 2$$

2. 求整數部分 $a$ 與小數部分 $b$：

因為 $2 \lt \sqrt{5} \lt 3$，所以 $4 \lt \sqrt{5} + 2 \lt 5$，故整數部分 $a = 4$，小數部分 $b = (\sqrt{5} + 2) - 4 = \sqrt{5} - 2$。

3. 計算 $b^2 + \dfrac{1}{b^2}$：先將 $\dfrac{1}{b}$ 有理化：

$$\frac{1}{b} = \frac{1}{\sqrt{5} - 2} = \frac{\sqrt{5} + 2}{(\sqrt{5} - 2)(\sqrt{5} + 2)} = \sqrt{5} + 2$$

因此 $b + \dfrac{1}{b} = (\sqrt{5} - 2) + (\sqrt{5} + 2) = 2\sqrt{5}$，代入乘法公式：

$$b^2 + \frac{1}{b^2} = \left(b + \frac{1}{b}\right)^2 - 2 = (2\sqrt{5})^2 - 2 = 20 - 2 = 18$$

答：$a = 4$，$b = \sqrt{5} - 2$，$b^2 + \dfrac{1}{b^2} = 18$
